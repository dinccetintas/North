# M6 — Subscription and launch

Goal: plans and credits are live in Stripe test mode, usage is visible, data and
code export work, the PWA installs, and the founder's own company runs for 30
days on the platform.

Requirements: BIL-1, BIL-2, EXP-1, MULTI-1 (portfolio brief), mobile PWA.

## Deliverables

- Stripe Billing: Solo/Pro/Scale products from config, checkout, portal,
  webhooks → entitlements; credits per plan; one-off credit packs; agents stop
  when the subscription ends, data kept 90 days, export available.
- Usage panel: per-user monthly inference + sandbox cost vs plan price (alert at 40%).
- Export: artifacts (MD/PDF/PPTX), data (JSON/CSV), repo already in user's GitHub.
- PWA: manifest, service worker, install prompt, offline brief cache.
- Portfolio page `/companies` with one brief across companies (MULTI-1).
- Public company page `/p/[slug]` (opt-in).
- Legal placeholders: terms, privacy, acceptable use (counsel review before launch).
- Production: Vercel (web), container host (worker), hosted Supabase, Inngest Cloud.

## Acceptance test

Stripe test-mode E2E: subscribe → entitlements → create second company blocked
on Solo → upgrade → allowed → cancel → agents paused → export downloads.
Lighthouse PWA installable; `pnpm validate` and `pnpm e2e` green in CI; the
founder's company created and running (evidence under `docs/evidence/M6/`).
