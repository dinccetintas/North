# M0 — Skeleton

Goal: a user signs up, creates a company, and RLS proves one user cannot see
another's company. Foundations for everything after: monorepo, database, auth,
agent role loader, durable queue, validation layer, CI.

Requirements touched: EXP-1 (repo is the user's), security NFRs, BIL-1 (Stripe
test mode wiring only).

## Deliverables

- `pnpm-workspace.yaml`, root `package.json` scripts (`dev`, `db:start`,
  `db:reset`, `validate`, `e2e`), `tsconfig.base.json`, ESLint flat config, Vitest.
- `apps/web`: Next.js 16 app, Tailwind v4 tokens, `proxy.ts` with Supabase SSR
  session refresh, `/login` (Google + magic link), `/auth/callback`, `/new`
  (company name + thesis only in M0), `/c/[slug]` shell with kill-switch button,
  `/api/inngest` serve route.
- `packages/db`: `supabase/config.toml`, migration `0001_init.sql` with all
  tables from the design (§7), RLS policies, append-only triggers, constraints;
  `seed.sql`; generated `types.ts`; repositories for companies/users.
- `packages/core`: `models.ts`, `authority/` skeleton with tier enums and
  `classify()` for the spec's rule table (tests), `quota.ts` (tests).
- `packages/agents`: `roles/loader.ts` reading `agents/*.yaml` (Zod), tests.
- `apps/worker`: Inngest client, `serve` via Hono on :3001, a `ping` function,
  `MockRuntime` stub.
- `scripts/smoke.ts` (M0 version: create user + company through the API under
  RLS, assert isolation), `scripts/validate.sh`.
- `.github/workflows/ci.yml`.

## Steps

1. Scaffold monorepo and `apps/web` with `create-next-app@16` (TS, Tailwind,
   App Router, `src/`), remove boilerplate, add tokens and fonts.
2. `supabase init` under `packages/db`, write `0001_init.sql`, start locally,
   generate types.
3. Supabase SSR clients (`browser.ts`, `server.ts`, `proxy.ts`), login page,
   callback, protected layout.
4. Company creation (server action + repository), `/c/[slug]` shell.
5. Core modules with tests first; role loader with tests.
6. Worker + Inngest Dev Server wiring; `pnpm dev` runs all three.
7. RLS integration tests; smoke; CI.

## Acceptance test

```bash
pnpm validate
```
Must include `packages/db/test/rls.test.ts`: user A creates company A, user B
creates company B; A's client cannot `select`, `update` or `delete` B's company
or any child row; service role can. Plus a Playwright flow: magic-link sign-in
through the local Inbucket, create a company, land on `/c/[slug]`.

## Acceptance evidence (2026-10-14)

- `pnpm -r typecheck`, `pnpm -r lint`: clean across 6 workspace packages.
- Unit: `packages/core` 36 tests (coverage 96% statements), `packages/agents` 5 tests.
- Integration (local Supabase on Colima): `packages/db` 13 tests. RLS: owner A
  cannot select/update/delete owner B's company or theses; forged owner insert
  rejected; profile auto-created on sign-up. Constraints: K2 action without
  card/auto rule rejected, K3 with auto rule rejected (DEC-1); 4th card of the
  day rejected at quota 3 (DEC-3); K3 default option rejected; `done` without
  evidence rejected (AGT-2); UPDATE/DELETE on `actions`/`ledger_entries`
  rejected even for the service role.
- Smoke: `pnpm smoke` (roles, gate K0/K2/kill switch, quota, evidence-only done).
- E2E (Playwright 1.64.1, chromium headless shell 1248): magic link read from
  Mailpit → `/companies` → create "Cold Hive" → `/c/cold-hive` shows the name,
  "Decisions today", and the kill switch; toggling it shows "All agents are
  stopped". Passed on desktop (1280px) and mobile (390px) in 3.6 s.
  Screenshots: `docs/evidence/M0/company-home-desktop.png`, `company-home-mobile.png`.
- Inngest Dev Server (http://localhost:8288) syncs both apps: `north-web`
  (1 function) and `north-worker` (2 functions).

Environment notes: Docker Desktop 4.47 on this machine does not launch
(DockerHelper starts and terminates), so the container runtime is Colima
(`colima start --cpu 4 --memory 6 --disk 40`). Ports 3000/3001 are used by
other projects on this machine; North runs web on 3100 and worker on 3101.
Workspace packages use extensionless relative imports because Turbopack does
not map `./x.js` to `./x.ts`.
