# M1 — Core loop (K0 only)

Goal: from an idea text, within 24 hours the company has a market report,
personas, a PRD, a business plan and an investor deck draft as versioned
artifacts, and a weekly plan from the Chief of Staff. No external action yet.

Requirements: ONB-1, ONB-2, PLN-1, MEM-1, MEM-2, AGT-1 (statuses), CHAT-1 (basic).

## Deliverables

- Onboarding flow `/new`: idea text → ≤5 clarifying questions (Haiku/Sonnet
  structured output) → thesis saved (versioned) → goal (metric, target, date) →
  budget categories and daily caps → summary.
- `packages/agents`: Chief of Staff, Research, Strategy roles wired to
  `ClaudeAgentSdkRuntime` with structured outputs (`Plan`, `MarketReport`,
  `Personas`, `PRD`, `BusinessPlan`, `Deck`); `MockRuntime` fixtures for each.
- `apps/worker` functions: `onboard-company`, `plan-week`, `run-task` (K0 path
  only: run → evidence (artifact id) → done → ledger entry with cost).
- Company memory: `memory_items` writes from every artifact; embedding via the
  Anthropic-compatible embedding provider configured in `packages/db/embeddings`
  (sandbox: deterministic hash vectors); search tool for agents.
- Artifacts: Storage upload, versions, download as MD (PDF/PPTX in M6 polish).
- UI: `/c/[slug]` shows brief placeholder, plan, tasks with statuses; `/artifacts`.
- Chief of Staff chat (optional) with memory context; decisions from chat are
  written to memory.

## Acceptance test

`scripts/smoke.ts --until M1` with `MockRuntime`: after `company/onboarded`,
within the run the company has ≥4 artifacts, a plan with tasks that each carry
an owner role, expected metric delta and cost estimate, every task `done` with
evidence, and ledger entries. Playwright: complete onboarding on a 390px
viewport in under 10 minutes of user time (ONB-1 acceptance proxy).

A separate manual run with `ClaudeAgentSdkRuntime` on a real idea is recorded
under `docs/evidence/M1/` (artifact samples, cost per task).
