- 2026-10-16 — Task 11 (SEC-1, TST-1, TST-2): loopback model gateway (`apps/worker/src/gateway/`: `server.ts`, `cassette.ts`, `budget.ts`, plus `headers.ts`, `usage.ts`, `capture.ts`, `options.ts`; `cassettes/README.md`). Prices verified against the official pricing page on 2026-10-16, USD per million tokens (input / 5-minute cache write / 1-hour cache write / cache read / output): `claude-opus-5-5` 4 / 5 / 8 / 0.20 / 20; `claude-sonnet-5-5` 2 / 2.50 / 4 / 0.10 / 10; `claude-haiku-5-5` for prompts up to 100,000 tokens 0.10 / 0.125 / 0.20 / 0.01 / 0.50 and over 100,000 tokens 0.50 / 0.625 / 1 / 0.05 / 2.50 (prompt = input + cache reads + cache writes, priced per request; the tier switches at 100,001). `costOfUsage` now prices all five kinds; `usageFromApi` (core) maps an API `usage` plus `model`, reading `cache_creation.ephemeral_{5m,1h}_input_tokens` and falling back to `cache_creation_input_tokens` as 5-minute writes. The gateway binds 127.0.0.1, refuses a non-loopback Host (403) and any key but the placeholder (401), proxies only `POST /v1/messages[/count_tokens]`, streams SSE byte for byte, prices `message_start` + the final `message_delta`, answers 402 once the UTC day's cap is reached, and in record/replay stores and serves cassettes keyed by the normalised request. Not wired yet: Task 12 adds `NORTH_CASSETTE_MODE` (`off|record|replay`, `off` = gateway `live`), `NORTH_CASSETTE_DIR`, `NORTH_DAILY_CAP_USD` to the worker env and deps; `.env.example` documents them. Spend the gateway cannot price (unknown model id, unreadable usage, reply over 8 MB or compressed) is counted in `stats().unpriced` and is not capped.
