# M2 — Decision layer

Goal: no K2/K3 action can run without an answered card; the daily quota is never
exceeded; cards arrive by push and email; the kill switch stops everything in 5 s;
every action is in the audit log. This milestone must be complete before any
agent touches the outside world (M3, M4).

Requirements: DEC-1, DEC-2, DEC-3, kill switch, audit NFR.

## Deliverables

- `packages/core/authority`: full `classify()` and `gate()` with the spec's rule
  table, budget caps, auto rules, kill switch state; 100% branch coverage.
- `packages/core/decisions`: quota ranking/merging, safe defaults, auto-rule
  suggestion after three identical answers.
- Database: constraints (K2/K3 require card), partial unique index for quota,
  `auto_rules`, `actions` append-only trigger tests.
- Worker: `run-task` K2 path with `step.waitForEvent("decision/answered")`,
  timeout → default; `kill-switch` function with `cancelOn` on all agent
  functions; sandbox adapters receive the executed action.
- Web: `/c/[slug]` morning screen (≤3 cards), card detail, answer in one tap,
  "don't ask again" → auto-rule acceptance; settings for quota; push
  subscription (web-push) and Resend email for new cards; kill switch button
  wired everywhere; action stream on `/team`.

## Acceptance test

`packages/core/test/authority.test.ts` and `packages/db/test/dec1.test.ts`:
every K2/K3 action attempted without a card is rejected by the engine and by the
database. `packages/core/test/quota.test.ts`: 10 candidate cards on one day →
exactly 3 opened, rest merged/deferred, none lost. Integration: a running
sandbox campaign plus 3 queued tasks → `company/killswitch` → all cancelled and
campaign paused within 5 s (measured). E2E: answer a card on mobile; the
`decision/answered` event is visible in the Inngest Dev Server within 2 s.
