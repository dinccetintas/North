# M3 — Build and design

Goal: from the PRD, a landing page is live on a preview URL; going live is a K2
card; the deploy URL is the evidence. Repo lives in the user's GitHub.

Requirements: AGT-1, AGT-2, AGT-3, EXP-1, ONB-3 (GitHub + Vercel connections).

## Deliverables

- Connections: GitHub App install flow and Vercel OAuth (tokens in Vault);
  sandbox adapters for both; "connect" decision card when a task needs a missing
  connection (ONB-3: no crash).
- Engineering role: `ClaudeAgentSdkRuntime` with file tools + Bash inside a
  per-task workspace (`.workspaces/<taskId>`), SDK sandbox network allowlist,
  `maxBudgetUsd`; creates the repo in the user's account, pushes, triggers a
  Vercel preview; evidence = preview URL verified 200 + deploy ID.
- Design role: brand kit + screen designs as artifacts (image generation adapter
  with sandbox placeholders).
- Attempt policy: two strategies then escalate to Chief of Staff (AGT-3).
- Verifier module: evidence checks per kind (URL, deploy, message, test report).
- Worker hosting decision (Fly/Railway) and a Dockerfile.

## Acceptance test

Smoke with sandbox adapters: PRD → engineering task → repo created (sandbox
record) → preview URL evidence → `go-live` K2 card → answer → production deploy
evidence recorded. One real run with live GitHub + Vercel on the founder's
account recorded under `docs/evidence/M3/` (preview URL, deploy ID, cost).
Eval: a task returning "done" without evidence fails.
